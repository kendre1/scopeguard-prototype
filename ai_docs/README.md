# ai_docs — Curated documentation for agents

High-signal reference material you want Claude to have on hand during a session. This is the project's persistent, agent-facing knowledge base — the things that aren't obvious from the code and that you'd otherwise paste into the chat repeatedly.

Good candidates:
- Condensed docs for key libraries, SDKs, or APIs the project uses.
- Internal architecture notes, data models, or domain glossaries.
- Integration guides, runbooks, and gotchas.

Keep entries focused and current. Reference them from `CLAUDE.md` or from specific commands when relevant so the agent knows they exist.

> athema scaffolds this directory; fill it with docs specific to your project. Delete it if you have no use for it yet.
